# This-is-fast-SPI-library-for-Nokia-displays-based-on-the-SPFD54124B-controller
This is fast SPI library for displays based on the SPFD54124B controller, it is also compatible with displays using other controllers found in various Nokia phones  (such as the Nokia 1616, 1661, 1800, C1-00, C1-01, X1-01, 2330c, 2630, 2680, 3110c, 3500c, 5030, and others).
